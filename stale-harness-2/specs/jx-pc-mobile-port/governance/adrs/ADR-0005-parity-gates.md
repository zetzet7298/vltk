# ADR-0005: Parity dùng evidence hai tầng

- **Trạng thái:** Chấp nhận
- **Quyết định:** Static evidence cho phép implementation; `PARITY_DONE` cần runtime golden. Skill logic 100%, visual từng case SSIM >= 0.99.
- **Hệ quả:** Placeholder/fallback không qua gate; scale/crop đúng asset nhưng chưa chuẩn là `VISUAL_DEBT`.
