## Top Priority Fixes

### 1. Skill 357 (Phi Long Tại Thiên) - BLOCK
* **Description**: Mobile `CombatRuntimeService.cs` (line 218) spawns the collision sub-skill 389 (Long Chiến Ư Dã) **instantly upon cast** instead of waiting for the missile of 357 to reach the target (`skill_collideevent`). This makes the second-stage damage and visuals apply instantly without flight delay, giving the player an incorrect combat advantage.
* **Fix**: Refactor `CombatRuntimeService` to register a callback trigger on projectile impact, spawning 389 visuals and applying damage only upon missile collision.

### 2. Confuse Probability Bloat - GAP
* **Description**: Damage skills 117, 119, 122, 125, 128, 357, 359, 1073, 1074 all have hardcoded `ConfuseP` buff state values in `PcCombatCatalogFactory.cs` (e.g. 10% to 80% confusion probability) which do not exist anywhere in the PC `gaibang.lua` tables or `skills.txt` rows.
* **Fix**: Remove `extra: (lv) => State(MagicAttributeKind.ConfuseP, ...)` logic from these skill registrations in `PcCombatCatalogFactory.cs`.

### 3. ByMissle Mismatch - GAP
* **Description**: Mobile seeds `byMissile` = true for active skills 117, 119, 122, 125, 128, 359 (delaying damage until visual projectile hits), whereas PC has `ByMissle` = 0 (instantly applying damage upon cast).
* **Fix**: Update the `DamageSkillNew` invocations for these skills to set `byMissile = false` in `PcCombatCatalogFactory.cs`.

### 4. MaxLevel 26 for 150-tier Skills - GAP
