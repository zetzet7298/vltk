# ADR-0001: Active Vietnamese runtime là source authority

- **Trạng thái:** Chấp nhận
- **Quyết định:** Chỉ chọn asset/config từ manifest runtime tiếng Việt active và first-match loader; mọi mâu thuẫn vào ledger.
- **Hệ quả:** Không được suy phiên bản mới bằng tên/mtime; vltktool provenance là gate bắt buộc.
