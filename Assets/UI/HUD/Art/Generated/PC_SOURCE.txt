Important hash detail:
JX PAK lookup for Chinese paths requires signed-byte hashing. Unsigned-byte lookup failed; signed-byte hash matched the exact Skills.txt icon paths.

Important orientation detail:
PC DrawSkillIcon draws SPR frame 0 through screen-space DrawSpriteAlpha. Texture V coordinates go top-to-bottom (tv 0 -> tv fV2), so decoded Unity PNGs must be vertically flipped from the raw bottom-up row decode used by the generic SPR decoder. These exported PNGs are exact PC skill SPRs with that PC UI orientation correction applied.

PC UI order / layout note:
KUiFightSkill.UpdateData calls GDI_FIGHT_SKILLS; CoreShell forwards to KSkillList::GetSkillSortList, which iterates KSkillList insertion order. The sandbox Cái Bang open seeds the PC Cái Bang skill list in Skills.txt/faction order, laid into UiSkillsFightSub.ini slots Skill_0..Skill_24 row-major (5 columns). Level text uses UiSkillsFightSub.ini SkillText Offset=0,36 and is drawn only when Obj.DataW != 0. Current Unity overlay clears each 36x50 slot before redrawing PC icon + current level to prevent stale/baked screenshot text overlap.
