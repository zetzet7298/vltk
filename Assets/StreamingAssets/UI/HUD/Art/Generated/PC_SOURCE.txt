MOD data PAKs: /tmp/server_client_001/bin/client/data/update01.pak .. updatejx14.pak
MOD PAK UID lookup: vltktool/unpak_tool.py::file_id_from_bytes (signed-char variant for CJK bytes)
PAK header: "PACK" + count(u32) + index_offset(u32) + data_offset(u32) + crc32 + 12 reserved bytes
PAK entry:  uid(u32) + offset(u32) + size(u32) + compress_size(i32)  -- top 8 bits = method, low 24 bits = compressed size

Source PAK:
/var/www/vhst/survivors/external-data/vltklinux/data/spr.pak (PC gốc spr.pak, 738MB)
/tmp/server_client_001/bin/client/data/updatejx08.pak (MOD 150-tier GB icons)
hex(signed-char hash) verified against existing PC gốc UIDs in this folder.

Important hash detail:
JX PAK lookup for Chinese paths requires PC signed-byte FileNameHash behavior. Unsigned-byte lookup maps to wrong/missing UIDs.

Important caveat:
The PC JX1 original Skills.txt contains Cái Bang range 115-130 (16 skills including 125, 128). It does
NOT contain Phi Long Tại Thiên (357), Tiêu Dao Công (360), 274, 277, 1073, 1074, 1539, or the
MOD-only player variant of Thiên Hạ Vô Cẩu (359). All seven (274, 277, 357, 359, 360, 1073, 1074) plus
the NPC variant (1539) come from MOD source (StreamingAssets/Reference/gaibang.lua).

The mobile client treats MOD as the source of truth for these 8 new IDs but uses PC gốc PC UI layout
(战斗技能细分页.ini 5x5 grid, 25 slots per page) for the Cái Bang skill panel.
