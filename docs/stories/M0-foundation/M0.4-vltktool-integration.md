## Integration Points for Unity

1. **SPR Pipeline**: vltktool decodes SPR -> PNG. Unity can also decode SPR directly via `VLTK.Sprites.SprDecoder`.
2. **Map Data**: maps_pak files have hash names (e.g. `00002d56.dat`). Need UID->path mapping.
3. **Item Data**: vltktool generates JSON catalogs that Unity can consume.
4. **Conversion Manifest**: Each conversion should record vltktool version and git commit.
